# 虹光衝刺

一款彩虹主題的小恐龍跑酷遊戲。跳過地面障礙、蹲下閃開低空障礙，挑戰逐漸加快的節奏，收集成就並解鎖不同的小恐龍造型。

## 遊戲特色

- **四個場景**：每 500 分切換場景，通過極光雪境後再次循環；每個場景都有自己的障礙。
- **越跑越快**：一般速度最高 2.5 倍，虹光龍的衝刺技能可短暫提高至 2.75 倍。
- **收集與挑戰**：七個成就、四款造型及各自的主動技能；最高分與成就保存在目前的瀏覽器。

## 操作方式

| 動作 | 電腦 | 手機、平板 |
| --- | --- | --- |
| 跳躍 | 空白鍵、↑ 或 W | 點「跳躍」 |
| 蹲下 | 按住 ↓ 或 S | 按住「蹲下」 |
| 技能 | Shift 或 X | 點「技能」 |
| 暫停／繼續 | P 或 Esc | 點「暫停／繼續」 |

畫面右側的 **↑／↓** 提示下一個障礙適合用跳躍或蹲下通過。
