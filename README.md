# 龍行江湖

一款武俠風格的小恐龍跑酷遊戲。躍過地面路障、蹲下閃開低空障礙，穿越四處江湖勝景，挑戰逐漸加快的節奏，收集成就並解鎖角色造型。

## 遊戲特色

- **四處江湖勝景**：青竹山徑、桃花渡口、雲崖劍谷與雪夜古關，每 500 分切換，之後循環。
- **清楚的路障提示**：四處場景的地面路障以暖色亮邊、飛行障礙以淺玉色亮邊搭配深色輪廓，在高速時更容易辨認。
- **越跑越快**：一般速度最高 2.5 倍；青嵐龍的「凌風身法」可短暫提高至 2.75 倍。
- **收集與挑戰**：八個成就、五款造型及各自的主動技能。單局達 5000 分可解鎖黑色哥吉拉，施放「光速破壞」清除畫面內前方所有障礙。技能冷卻皆為 5 秒；最高分與成就保存在目前瀏覽器。
- **音樂與音效**：`game music.mp3` 在曲尾前約 2 秒交疊循環；跳躍、蹲下與成功發動技能分別使用 `jump.mp3`、`air-blow5.mp3`、`skill.mp3`。音樂與音效可分別開關。

## 操作方式

| 動作 | 電腦 | 手機、平板 |
| --- | --- | --- |
| 跳躍 | 空白鍵、↑ 或 W | 點「跳躍」 |
| 蹲下 | 按住 ↓ 或 S | 按住「蹲下」 |
| 技能 | Shift 或 X | 點「技能」 |
| 暫停／繼續 | P 或 Esc | 點「暫停／繼續」 |

畫面右側的 **↑／↓** 提示下一個障礙適合用跳躍或蹲下通過。

遊戲結束後，請點選畫面上的「再玩一次」按鈕重新開局；也可先用 Tab 選到按鈕，再按 Enter 或空白鍵。

每次成功起跳、放開蹲下後再次進入蹲姿，或成功發動技能，都會播放一次對應音效；無效動作與長按造成的按鍵重複不會額外發聲。背景音樂在暫停後接續，重新開局時從頭播放。

「光速破壞」會立即清除畫面內、哥吉拉前方的地面及飛行障礙；已接觸角色或仍在畫面外的障礙不受影響。清除障礙不計入閃避類成就。若舊版最高分已達 5000 分，開啟新版時會補發解鎖。

## 檔案

- `index.html`：遊戲畫面與音訊元素。
- `game.js`：遊戲邏輯、技能與音訊控制。
- `assets/`：圖示、跳躍、蹲下、技能、得分、碰撞音效，以及背景音樂。發布或搬移遊戲時，請保留完整資料夾與檔名。
